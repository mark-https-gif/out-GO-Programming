## Короткое описание (Description — до 350 символов)

OUT — скриптовый язык программирования-обёртка над Go. Мощь Go с человеческим лицом: дружелюбный синтаксис + модули strings, math, http, json, crypto и мемные функции.

## Полное описание (About — расширенное)

OUT превращает мощь Go в дружелюбный и мемный скриптовый язык. Вы пишете простой код, а внутри работает весь Go-рантайм. Это как Python с C++, только OUT — с Go.
- Переменные, функции, if/else, while, for i in 1..5
- Массивы и словари
- Мем-функции: vibe(), yeet(), bruh(), flex(), sus()
- import между .out файлами
- Go-модули: strings::, math::, os::, strconv::, json::, http::, files::, crypto::, time::, list::
